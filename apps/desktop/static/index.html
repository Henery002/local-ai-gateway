快速指引

接入说明与提供商状态摘要。

账号资产管理

管理桌面端本地维护的 Codex 账号，并支持导入本机可复用授权。

Provider 服务配置

在此配置不通过终端注入的本地持久化参数，保存后网关将自动重启生效。

全局路由设置

设置全局默认回退使用的模型别名。

默认模型的作用

当第三方客户端没有显式指定模型，或策略路由未改写目标模型时，网关会把请求导向这里设置的默认模型别名。

策略路由（第二期）

按客户端标签或请求模型命中规则。建议先预演，再启用到实时推理链路。

策略路由使用说明
  • 一条规则 = 至少 1 个匹配条件 + 至少 1 个目标字段，可按客户端或模型把流量分配到不同模型、不同账号。
  • 目标会话 / 账号标识留空时，命中规则后仍沿用当前活动账号，适合你在账号页灵活切号。
  • 填写目标会话 / 账号标识后，命中规则的请求会固定走指定账号，适合给 OpenClaw 或 localRagHub 预留专用额度。
  • 多条规则按优先级生效，数字越小越先命中；只要命中第一条启用规则，就不会继续往下匹配。

路由预演

输入模拟请求条件，查看当前策略将解析到哪个模型和账号。

填写条件后点击“预演路由结果”查看命中情况。

会话型 Provider (Codex)

复用本地授权驱动，无需手动填写密钥。

Codex Provider 说明

这里控制 `codex-default` 背后实际使用的上游模型，以及额外暴露给第三方客户端的模型别名；不会影响你已经导入的账号数据。

可同时暴露多个 Codex 模型别名给第三方客户端，例如 `codex-5.4`、`codex-5.4-mini`、`codex-5.1-max`、`codex-5.1-mini`。

OpenAI-Compatible

接入标准的 OpenAI 兼容云端接口。

OpenAI-Compatible Provider 说明

这是额外的标准兼容 Provider，可与 Codex 同时存在；适合接入你自有的云端中转、官方 API 或其他 OpenAI 兼容服务。

本地模型 (Ollama)

接入本机运行的 Ollama 服务。

Ollama Provider 说明

用于把本机 Ollama 模型一并纳入本地网关管理。配置成功后，第三方客户端就能通过同一个网关入口同时访问 Codex 和 Ollama。

已注册 Provider 清单

当前网关真正加载并可被外部访问的 Provider 列表。

号池调度

把多个桌面端 Codex 账号编成一个动态号池，供命中的路由规则按额度阈值、冷却和有限重试自动挑号。

号池调度开关

关闭后，所有“号池调度”目标模式都会退化为普通路由，不会再自动切号。

号池与策略路由的关系
  • 策略路由只负责“把哪类请求导向哪个目标”；号池调度页负责“目标号池内部如何选账号、何时跳过、何时切下一个”。
  • 如果某条路由规则目标模式选择“号池调度”，并填写了某个池 ID，那么命中的请求会在该池内动态选择真实账号。
  • 如果你仍想手动切号，请继续使用“沿用当前活动账号”模式；这条链路不会被动态号池破坏。
  • 第一版动态号池只纳入桌面端已导入账号，不直接把原始本地可复用授权当作正式池成员。

调度规则说明

先在这里定义池成员和自动切号策略，再到“服务配置 -> 策略路由”里把某类请求绑定到目标号池。

推荐使用方式

例如给 OpenClaw 配置一条 `clientTag=openclaw + model=codex-default -> 号池 A` 的策略路由，然后在号池 A 中放入多个桌面端 Codex 账号。网关会在每次请求开始前自动挑选一个满足阈值的账号；若本次请求命中的账号出现额度耗尽、鉴权失效或短期限流，会按池内策略尝试下一个候选账号。
