使用说明

桌面端是控制面，不是聊天窗口。

Codex 账号与授权

桌面端自己导入并管理的才是本应用内的 Codex 账号；OpenClaw 部分展示的是可复用的本地授权会话，不等同于本应用账号。

Provider 配置

在这里填写不想走终端的本地配置。保存后会自动重启 gateway 生效。

会话型 Provider

这里管理由本地 OAuth 授权驱动的会话型路由，当前仅包含 Codex。

Codex Provider

Codex 当前直接复用 `~/.openclaw` 中的本地 OAuth 授权，不需要手填 API Key。这里可以切换 `codex-default` 背后对应的上游模型。

云端兼容 Provider

用于接入标准 OpenAI-compatible 接口。当前界面只提供一个配置槽位。

OpenAI-compatible

若同时配置环境变量和界面表单，运行时会优先使用环境变量。

本地模型 Provider

用于接入本机运行的 Ollama 等本地模型服务。

Ollama

此处保存的是本机本地配置，适合你不想再通过终端反复设置的场景。

已注册 Provider

展示当前真正注册进网关并可被第三方应用访问的 provider 和模型别名。

诊断与错误

查看每个 Provider 的启用状态、缺失项与最近错误。

添加 Codex 账号

当前版本已经支持浏览器 OAuth 导入。点击下方按钮后会自动打开浏览器完成 OpenAI Codex 授权；若本地回调未自动完成，可把完整回调地址粘贴到输入框中继续。

浏览器授权已准备就绪。

当前版本已经支持导入常见 JSON 格式，包括 OpenClaw `auth-profiles.json`、单个 `openai-codex` OAuth 凭据对象，以及其他工具导出的兼容结构。

导入完成后，账号会写入本应用自己的本地存储，并出现在账号面板中。

这里预留 API Key 模式，用于未来支持 OpenAI-compatible / 其他官方 API Provider 的图形化接入。

当前版本会自动发现本机现有 OpenClaw 已登录的 Codex OAuth 会话。它们是可复用的授权来源，不直接等于本应用内的 Codex 账号。

如果你希望把某个 OpenClaw 已登录授权变成本应用自己的 Codex 账号，可在下方授权列表中点击“导入为桌面端账号”。
