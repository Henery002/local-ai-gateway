# 打包与发布说明

本文档描述 `Local AI Gateway` 当前的桌面打包与发布脚手架。

## 1. 当前目标

当前阶段的打包能力定位为：

- 先具备本地构建桌面包的基础能力
- 为后续发布流程预留统一脚手架
- 暂不追求完善的签名、公证与自动发布

当前已验证：

- `npm run package:desktop` 可生成目录包
- 产物位置为 `release/mac-arm64/Local AI Gateway.app`

## 2. 现有脚本

### 2.1 构建目录包

```bash
npm run package:desktop
```

该命令会：

1. 先执行 `npm run build`
2. 再通过 `electron-builder --dir` 生成目录形态的桌面包

### 2.2 构建可分发包

```bash
npm run dist:desktop
```

该命令会：

1. 先执行 `npm run build`
2. 再通过 `electron-builder` 生成 macOS 可分发产物

## 3. 打包配置

打包配置文件位于：

- [electron-builder.yml](/Users/henery/code/local-ai-gateway/electron-builder.yml)

当前约定：

- 输出目录：`release/`
- 产品名：`Local AI Gateway`
- 平台：macOS
- 目标格式：`zip`、`dmg`

当前实际状态：

- 目录包已验证可生成
- notarization 尚未接入，因此当前会跳过公证

## 4. 当前限制

当前脚手架仍属于基础版，后续建议继续补齐：

- 应用图标
- 代码签名
- notarization
- 版本号与产物命名策略
- 发布清单与校验信息

## 5. 建议发布前检查

在执行打包前，建议至少先运行：

```bash
npm run build
npm test
npm run smoke:gateway
```
