# 数据导出与迁移恢复

本文档用于说明如何在桌面端导出当前应用数据、在重装后恢复旧数据，以及这套能力当前覆盖的范围与注意事项。

## 1. 功能位置

桌面端左侧进入：

- `诊断 -> 系统配置 -> 数据迁移与恢复`

当前提供两个按钮：

- `导出应用数据`
- `导入应用数据`

## 2. 导出内容

当前导出为单个 JSON 备份文件，备份对象包括本地 App Support 目录中的持久化数据：

- `config.json`
- `codex-auth-profiles.json`
- `gateway.db`
- `gateway.db-wal`
- `gateway.db-shm`
- `logs/` 下的日志文件

说明：

- 备份会自动排除内部 `backups/` 目录，避免出现“备份套备份”的无限膨胀。
- 导出的重点是“恢复当前应用状态”，不是给人手动编辑。

## 3. 导入恢复

导入时会执行以下流程：

1. 选择一个此前导出的备份文件
2. 导入前，系统先在本机 `App Support/backups/` 目录自动生成一份安全备份
3. 用备份文件覆盖当前本机持久化数据
4. 若当前网关由桌面端托管，则自动重启托管网关
5. 若当前不是桌面端托管网关，则提示需要手动重启后完全生效

## 4. 适用场景

推荐用于：

- 卸载重装桌面端后恢复旧数据
- 在同一台机器上回滚到之前的稳定状态
- 在本地迁移配置、已导入账号、号池调度、路由规则和统计数据

## 5. 当前边界

- 当前恢复的是“本应用本地持久化数据”，不是外部第三方平台的远端数据
- 导入会覆盖当前本机数据，因此执行前请确认当前机器上的新数据是否需要保留
- 若你当前使用的是非桌面端托管的外部 gateway 进程，导入完成后需要手动重启该进程
