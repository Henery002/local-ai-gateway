# ADR 0001：服务优先于桌面壳

## 状态

已采纳

## 日期

2026-03-25

## 背景

项目需要同时提供本地服务能力与 Electron 控制台，但首版最核心的价值是让 OpenClaw 通过本地地址稳定调用 Codex。

## 决策

首版仍然坚持：

- gateway service 是核心执行层
- Electron 只是控制面
- 即使桌面壳进入 v1 交付，服务也必须保持可独立运行与调试

## 影响

- 所有推理逻辑只放在 gateway 内，不放到 Electron 中
- Electron 通过 Admin API 控制服务，而不是直接接 provider
- 后续调试、联调、自动化 smoke 都围绕 gateway 展开
