> 2026.05.17

本文档用于跟踪 `Local AI Gateway` 共享网关二期 / 三期重构的实际开发节奏。技术目标以《二期 / 三期共享网关重构技术方案》为准，UI/UX 输入以本机「figma UI/UX重构方案」为设计基线。

## 1. 当前结论

- 当前开发分支：`codex/shared-gateway-next`。
- 当前工作阶段：UI/UX Phase 1-12 已阶段性收口；功能开发恢复到 `P1-B / P1-C / P2-A`，并已补上 LAN 成员访问 private 号池的执行层隔离第一段、consumer 路由预演第一段、AccessPolicy UI 编辑第一段、日额度余量展示第一段、QPS / 并发运行态解释第一段和成员策略告警摘要第一段。
- 当前不做：公网真实开放、公开注册、计费、多租户运营、Cockpit / OpenClaw 原始配置写入。
- 当前暂停点：UI/UX 侧已标记为阶段性暂停；后续只在功能切片需要新交互或真实数据态时顺手精修。
- 当前优先级：继续功能闭环，优先顺序为 P2-A 用量告警真实数据、成员级趋势与告警事件，以及三期 `public-ready` / `public-user` 的后续策略边界。

### 切片 6：P1-B AccessConsumer / AccessKey / AccessPolicy

- 已支持 `limits.requestsPerMinute` 的推理前置拦截：按成员近 60 秒已记录请求数限流，超额返回 `429 access_policy_rate_limit_exceeded`。
