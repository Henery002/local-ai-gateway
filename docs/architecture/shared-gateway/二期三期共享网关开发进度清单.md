# 二期 / 三期共享网关开发进度清单

> 2026.05.17

本文档用于跟踪 `Local AI Gateway` 共享网关二期 / 三期重构的实际开发节奏。技术目标以《二期 / 三期共享网关重构技术方案》为准，UI/UX 输入以本机「figma UI/UX重构方案」为设计基线。

## 1. 当前结论

- 当前开发分支：`codex/shared-gateway-next`。
- 当前工作阶段：`P1-B AccessConsumer / AccessKey / AccessPolicy` 已完成后端内核、成员创建、成员详情 / key 状态管理、成员日 Token 限额、QPS、并发限制、`allowedPoolIds` 号池授权执行层第一段；`P1-C` 已完成号池 `visibility` 配置模型和号池卡片可见性编辑第一段。下一步补成员授权 UI、策略 UI 编辑、余量展示和 consumer 路由预演。
- 当前不做：公网真实开放、公开注册、计费、多租户运营、Cockpit / OpenClaw 原始配置写入。
- 当前优先级：先把桌面端 UI/UX、访问成员模型和共享网关安全边界对齐，再恢复 AccessPolicy、号池授权和用量告警功能开发。

### 切片 6：P1-B AccessConsumer / AccessKey / AccessPolicy

- 已支持保存访问者 key 时只持久化 `keyHash / keyPrefix / keySuffix / status`，管理接口只返回脱敏 key 元数据，不回传明文 key。
- 已支持推理面通过 API key hash 匹配访问者 key，并解析到访问者 `clientTag`，继续兼容现有路由和用量统计。
